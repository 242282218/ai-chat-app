# 基础架构与代码索引

更新日期：2026-06-09

## 当前范围

项目是原生 Android AI 聊天应用，只保留聊天、图片输入和图片生成。已删除工具平台、Gateway、提示词预设、长期记忆、数据导入导出和多余设置入口。

## 文档入口

- `docs/优化路线图.md`：当前产品边界和近期优先级。
- `docs/同类项目调研.md`：同类 Android/移动 AI 客户端调研结论。
- `docs/界面体验优化路线图.md`：移动端界面体验优化记录。
- `docs/优化总结报告.md`：历史瘦身和界面优化结果记录。

## 代码入口

- `app/src/main/java/com/aichat/workbench/app/`：Application、Koin 依赖注入和数据库初始化。
- `app/src/main/java/com/aichat/workbench/navigation/`：底部导航和页面路由，目前是对话、图片、模型。
- `app/src/main/java/com/aichat/workbench/feature/chat/`：聊天页面、会话上下文、发送编排和长对话压缩。
- `app/src/main/java/com/aichat/workbench/feature/image/`：图片生成页面、图片参数、历史记录和复用提示词。
- `app/src/main/java/com/aichat/workbench/feature/provider/`：Provider 配置、模型发现、API Key 状态和聊天/图片模型选择；底部“模型”页直接进入这里。
- `app/src/main/java/com/aichat/workbench/data/local/`：Room 数据库、DAO、entity 和迁移。当前 schema version 是 18。
- `app/src/main/java/com/aichat/workbench/provider/`：OpenAI 和 OpenAI-compatible 聊天协议、图片生成协议、Provider 能力推断。

## 数据模型

- `ConversationEntity` / `MessageEntity`：本地会话和消息。
- `ProviderConfigEntity`：Provider 地址、类型、模型列表和已保存密钥引用。
- `ModelRolePreferenceEntity`：聊天和图片角色的模型选择。
- `ImageGenerationEntity`：图片生成历史和本地图片 URI。

## 验证

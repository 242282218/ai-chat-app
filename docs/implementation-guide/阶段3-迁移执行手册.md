```kotlin
/**
 * Sync messages from Room to Stream Channel (in-memory only)
 */
suspend fun syncMessagesToChannel(
    channelId: String,
    messages: List<Message>,
    currentUser: User
): Result<Unit> {
    return try {
        val channel = chatClient.channel(channelId)

        // Create or update channel
        channel.create(
            members = listOf(currentUser.id, "ai_assistant"),
            extraData = mapOf("synced" to true)
        ).await()

        // Note: Stream SDK doesn't support direct message injection
        // Messages will be synced through actual send operations
        Result.success(Unit)
    } catch (e: Exception) {
        Result.failure(e)
    }
}
```

## 常见问题

### Q1: 数据同步延迟

**现象**: Stream UI 显示的消息比 Room 慢

**解决**:
- 检查 LaunchedEffect 是否正确触发
- 增加日志追踪数据流
- 考虑使用 StateFlow 优化

### Q2: 消息重复显示

**现象**: 同一条消息出现多次

**解决**:
- 检查消息 ID 唯一性
- 确保没有重复的数据源
- 检查 LaunchedEffect 依赖

### Q3: 输入框状态丢失

**现象**: 切换对话后输入框内容没清空

**解决**:
- 使用 `rememberSaveable` 或 ViewModel
- 监听对话切换事件
- 手动清空输入状态

   - Stream SDK 初始化放在后台
   - 延迟加载非关键组件
   - 优化依赖注入

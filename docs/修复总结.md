### 2. ✅ Repository 异常处理（高优先级）

**问题**: Repository 层无异常处理，数据库错误直接传播到 UI 层

**修复内容**:

  - `observeConversations()` - 捕获 Flow 异常
  - `getConversation()` - 捕获查询异常
  - `saveConversation()` - 捕获保存异常
  - `saveMessage()` - 捕获消息保存异常
  - `deleteConversation()` - 捕获删除异常
  - `deleteMessages()` - 捕获批量删除异常
  - 所有 Flow 方法使用 `.catch { }` 转换异常

**影响**: 
- 数据库异常现在会转换为用户友好的错误消息
- UI 层可以统一处理 `RepositoryException`
- 便于后续添加错误上报和日志记录

   private fun hasEnoughSpace(directory: File, requiredBytes: Long): Boolean

**影响**:

- 提供清晰的错误消息

### 4. ✅ 主线程图片解码修复（高优先级）

**问题**: 主线程同步解码图片导致 UI 卡顿

**修复内容** (`ImageGenerationLibrary.kt`):

**修复前**:
```kotlin
@Composable
private fun LocalThumbnail(path: String) {
    val bitmap = remember(path) {
        BitmapFactory.decodeFile(path)?.asImageBitmap()  // ⚠️ 主线程阻塞
    }
}
```

**修复后**:
```kotlin
@Composable
private fun LocalThumbnail(path: String) {
    var bitmap by remember { mutableStateOf<ImageBitmap?>(null) }
    var isLoading by remember { mutableStateOf(true) }

    LaunchedEffect(path) {
        bitmap = withContext(Dispatchers.IO) {
            try {
                BitmapFactory.decodeFile(path)?.asImageBitmap()
            } catch (e: Exception) {
                null
            }
        }
        isLoading = false
    }

    if (isLoading) {
        // 显示加载动画
        CircularProgressIndicator()
        return
    }
    // 显示图片...
}
```

**影响**:
- 图片解码在后台线程执行
- 加载时显示进度指示器
- 异常捕获防止崩溃
- 显著改善 UI 流畅度

### 5. ✅ 网络安全配置（中优先级）

**问题**: 缺少网络安全配置，无法强制 HTTPS

**修复内容**:

1. 创建 `res/xml/network_security_config.xml`:
   ```xml
   <network-security-config>
       <base-config cleartextTrafficPermitted="false">
           <trust-anchors>
               <certificates src="system" />
           </trust-anchors>
       </base-config>
       <!-- 允许 localhost 和本地网络用于开发 -->
       <domain-config cleartextTrafficPermitted="true">
           <domain includeSubdomains="true">localhost</domain>
           <domain includeSubdomains="true">192.168.0.0/16</domain>
       </domain-config>
   </network-security-config>
   ```

2. 在 `AndroidManifest.xml` 中引用:
   ```xml
   android:networkSecurityConfig="@xml/network_security_config"
   ```

**影响**:
- 默认强制 HTTPS，防止中间人攻击
- 允许 localhost 和局域网 HTTP（用于 Ollama 等自建服务）
- 增强应用安全性

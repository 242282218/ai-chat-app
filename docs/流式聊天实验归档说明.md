# 流式聊天实验归档说明

## 当前状态

流式聊天实验已经从当前主线代码中移除。`app/src/main/java/com/aichat/workbench/stream/` 下的实验入口不再作为应用实现的一部分，聊天主路径继续使用 `app/src/main/java/com/aichat/workbench/feature/chat/` 下的自研 Jetpack Compose 实现。

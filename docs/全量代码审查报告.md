# 全量代码审查报告

## 审查范围

- Android App：Provider 配置、聊天发送、图片生成、Room 数据层、Compose UI、主题、Markdown 渲染、测试。
- Gateway：配置、HTTP API、搜索、Sandbox、测试。
- CI/CD：Android、Gateway、Release workflow。
- 配置与文档：`.env.example`、README、Provider 示例、优化计划、设计系统说明。

## 结论

当前代码可以提交到 `main` 并通过 GitHub Actions 构建新版本。没有发现真实 API Key 落盘；新增 Provider 能复用 OpenAI 兼容协议；图片生成路径会按 `/v1/images/generations` 请求。

## 重点审查项

- Provider：`newapi`、`sub2api`、`custom` 已加入类型、描述符、注册表和 UI 选项；未知 Provider 保留自定义描述符回退。
- Endpoint：聊天、模型发现、图片生成共用 Base URL 规范化；根地址会自动补 `/v1`，Ollama 模型发现会去掉 `/v1`。
- 安全：API Key 仍通过本地 SecretStore 或 GitHub Secrets/环境变量占位传入；`.env` 已忽略，`.env.example` 只保留占位符。
- 性能：Markdown 解析新增有界 LRU 缓存，降低长对话刷新时的重复解析。
- 包体：release 已同时开启混淆和资源压缩；未移除 `material-icons-extended`，因为现有页面广泛依赖，直接替换会扩大风险。
- UI/UX：默认关闭动态取色，使用固定 Material 3 色板；设计系统约束已写入文档。
- 发布：Release workflow 发布可安装 debug APK；未配置正式签名时不发布 unsigned release APK。

## 自动化验证

- `git diff --check`：通过。
- `gateway/go test ./...`：通过。
- `gateway/go vet ./...`：通过。
- 密钥扫描：未发现真实长格式 OpenAI Key。
- 本地 `go test -race ./...`：Windows 环境 `CGO_ENABLED=0`，race 需要在 GitHub Actions Ubuntu 环境运行。
- Android 本地验证：本机没有 Java；按当前要求交给 GitHub Actions 执行 `testDebugUnitTest lint assembleDebug assembleRelease`。

## 剩余风险

- Android 编译、lint 和单测必须以 GitHub Actions 结果为准。
- 产物为 debug APK，适合安装测试；正式 release APK 需要后续补签名配置后再发布。

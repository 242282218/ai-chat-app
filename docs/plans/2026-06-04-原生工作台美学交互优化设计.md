# 原生工作台美学交互优化设计

## 目标

本轮优化面向 Android 原生 AI 聊天工作台，目标是让首页、聊天页、图片页和主要管理页更接近成熟 AI 客户端的工作流体验，同时保持轻量：

- 首页优先承载会话、模型状态和主要行动。
- 聊天页优先保证输入、工具调用、图片输入和生成状态的闭环。
- 图片页优先保证提示词、图片模型、生成状态和作品复用的闭环。
- 模型、提示词、工具、数据页在顶栏和首屏摘要中直接暴露当前状态，减少进入详情后再判断可用性的成本。
- 继续只使用 Jetpack Compose 和 Material 3 原生组件，不新增 UI 依赖。

## 对标参考

本轮实现参考项目已有调研结论，重点吸收以下方向：

- RikkaHub、GPT Mobile：原生移动端 AI 客户端应保持移动端密度、触控和本地优先体验。
- NextChat：轻量、本地优先、提示词快捷入口和上下文工作流。
- LibreChat、Open WebUI：模型、工具、搜索、图片能力围绕当前会话组织。
- LobeChat：工具和模型能力需要可见、可选择、可恢复，而不是隐藏在深层配置。

## 视觉方向

采用原生 Material 3 的 `Evidence Warm Precision` 变体：

- 温暖浅底作为工作台背景，但用绿色、蓝色和赤陶色区分行动、工具和警告，不做单色系统。
- 卡片圆角保持 8dp，边框和留白承担层级，不使用玻璃拟态或大面积渐变。
- 状态 Pill、InlineNotice、工具确认面板展示真实系统状态，避免装饰性视觉。
- 图标使用现有 Material Icons，所有按钮保持原生触控和无障碍语义。

## 页面策略

### 首页

首屏结构：

1. 顶部操作：搜索、设置。
2. 工作台标题与模型状态摘要。
3. 主要行动区：新建会话、临时会话、图片生成、提示词入口。
4. 最近会话列表。

空状态提供可执行入口，不只显示提示文本。

### 聊天页

主路径：

1. 顶栏显示会话名、模型连接、生成状态。
2. 空会话展示起手式和模型配置状态。
3. 工具调用确认显示工具名、权限、参数和允许/拒绝。
4. 输入栏固定底部，图片、编辑、生成中、无模型连接状态都在输入区域内表达。

模型、工具、参数、提示词继续放在 Bottom Sheet，避免主聊天界面过载。

### 图片页

主路径：

1. 顶部标题显示生成状态。
2. 创作台先展示提示词和生成按钮。
3. 模型、尺寸、质量、数量以摘要和展开区呈现。
4. 作品库展示完成/失败状态，保留复用提示词、重新生成、保存、分享。

### 管理页

模型连接、提示词、工具和数据与隐私页保持原生 TopAppBar + 列表/Sheet 结构，但顶栏增加单行状态摘要：

1. 模型连接显示可用连接数和总连接数。
2. 提示词显示本地模板数量，搜索时显示匹配数。
3. 工具显示网关开关、清单加载和工具来源。
4. 数据与隐私显示导出、导入预览、忙碌状态和备份范围。

这些页面继续复用 `WorkbenchPanel`、`QuietSectionHeader`、`StatusPill` 和 `InlineNotice`，不引入自定义视觉框架。

# 设计系统说明

## 方向

AI Chat Workbench 是原生 Android 工作台，不做营销式界面。界面以内容、配置和状态反馈为核心，保持克制、清晰、可扫描。

## Token

- 颜色：使用 `ui/theme/Theme.kt` 中固定 Material 3 色板，默认不跟随动态取色，保证设备间视觉一致。
- 圆角：组件圆角控制在 6dp 到 8dp，避免过度圆润。
- 表面：普通内容使用 `surface`，辅助信息使用低透明度 `surfaceVariant`，危险状态使用 `error`。
- 状态：统一通过 `StatusTone` 表达 `Neutral`、`Accent`、`Success`、`Warning`、`Critical`。

## 组件

- `WorkbenchPanel`：用于单个可操作模块，不嵌套卡片。
- `QuietSectionHeader`：用于页面区块标题和说明。
- `StatusPill`：用于短状态、数量和风险标记。
- `InlineNotice`：用于错误、警告和需要用户处理的提示。
- `WorkbenchIconButton`：图标按钮统一 tooltip 和可访问名称。

## 交互

- 主流程按钮只保留必要操作，危险操作必须二次确认。
- 表单先给即时状态，再允许保存或测试。
- 长内容优先懒加载和折叠，工具消息默认可折叠。
- Markdown 消息解析使用有界缓存，降低长对话列表刷新时的重复解析成本。

## 后续约束

- 页面新增视觉元素时优先复用共享组件。
- 不引入重型 UI 依赖；图标优先使用已有 Material 图标。
- 不使用大面积渐变、装饰图形或品牌化 hero。

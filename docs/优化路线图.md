# 优化路线图

更新日期：2026-06-09

## 产品边界

当前主线只做聊天和图片。工具调用、Gateway、网页搜索、代码沙箱、Skill、Agent workflow、RAG、长期记忆、语音和本地模型运行时不进入近期范围。

## P0：稳定聊天和图片

- 保持聊天发送、流式响应、图片输入和错误恢复稳定。
- 保持图片生成历史、保存、分享和复用提示词稳定。
- Provider 设置只表达文本、视觉和图片能力。
- Android 单测和 lint 保持通过。

## P1：继续删减不可达边界

- 清理仍指向旧功能的文档、脚本、测试 fixture 和依赖。
- 保持旧版本数据库升级路径可用，但当前 schema 不再保留旧工具、提示词预设和长期记忆表。
- 检查导航、设置页、README 和 CI，只保留当前主线入口。

## P2：改善主路径体验

- 优化 Provider 模型发现、默认模型选择和图片模型选择。
- 优化聊天历史检索、长对话压缩和图片消息展示。
- 优化图片参数默认值、失败提示和历史筛选。

## 暂不做

- 不新增工具平台、外部 Gateway、搜索、沙箱或自动化工作流。
- 不新增角色卡、语音、TTS、本地推理或 RAG。
- 不恢复应用内数据导入导出，除非先重新设计隐私和文件格式边界。

# 优化路线图

更新日期：2026-06-13

## 产品边界

当前主线只做聊天和图片。工具调用、Gateway、网页搜索、代码沙箱、Skill、Agent workflow、RAG、长期记忆、语音和本地模型运行时不进入近期范围。

## P0：稳定聊天和图片

- 保持聊天发送、流式响应、图片输入和错误恢复稳定。
- 保持图片生成历史、保存、分享和复用提示词稳定。
- Provider 设置只表达文本、视觉和图片能力。
- Android 单测和 lint 保持通过。

## P1：继续删减不可达边界

- 清理仍指向旧功能的文档、脚本、测试 fixture 和依赖。
- 保持旧版本数据库升级路径可用，但当前 schema 不再保留旧工具、提示词预设和长期记忆表。
- 检查导航、模型页、README 和 CI，只保留当前主线入口。

## P2：改善主路径体验

- 优化 Provider 模型发现、默认模型选择和图片模型选择。
- 优化聊天历史检索、长对话压缩和图片消息展示。
- 优化图片参数默认值、失败提示和历史筛选。

## P3：UI/UX 美学重构 (2026-06-12 完成)

### 色彩系统
- 替换默认蓝紫 `#6366F1` 为独特的森林绿色系 (`#1B6B4A` / `#7FDAAE`)。
- 暗色模式使用温暖的薄荷绿主色，深色背景带绿色调。
- 中性色使用温暖灰调，避免冷蓝灰。
- accent 使用面积控制在 5-10%，中性色主导 70-90%。

### 字体排版
- 定义完整的 Typography scale：Display/Headline/Title/Body/Label 全系列。
- 标题使用 SemiBold/Medium，避免全部 Bold。
- 正文 16sp/24sp 行高，符合中文阅读最佳实践。
- letter-spacing 为 0（大标题）或 0.01-0.04sp（标签）。

### 聊天界面
- 消息泡添加头像标识（AI/U），增强用户/助手视觉区分。
- 助手消息使用 surfaceContainerLow 背景 + 细边框。
- 用户消息使用 primaryContainer 背景。
- 空消息显示打字指示动画。
- 压缩消息卡片使用更精致的图标设计。

### 对话列表
- 每个对话显示首字母头像圆圈。
- 添加相对时间显示（刚刚/N分钟前/N小时前）。
- 空状态使用居中图标+描述，更友好。
- 搜索输入框样式与新主题一致。

### 输入栏
- 更精致的边框和圆角。
- 发送按钮使用 primary 填充色。
- 停止按钮使用 error 色，语义更明确。

### 底部导航

- 选中指示器使用 10% primary 透明度。

### Markdown 渲染
- 引用块使用 2dp primary 色左边框，替代之前的普通边框。

## P3.51：历史重新生成 Provider 可用性修复 (2026-06-13)

### 问题
- 图片历史的“重新生成”会优先复用历史记录中的 Provider。
- 原逻辑只检查该 Provider 是否仍存在，没有检查是否启用。
- 当历史 Provider 已禁用时，重新生成仍可能切到禁用 Provider，并沿用其历史模型，导致 UI 可用状态和实际请求不一致。

### 修复
- `selectedProvider` 只返回当前启用的 Provider。
- `selectProvider()` 忽略禁用 Provider，避免外部调用绕过 UI disabled 状态。
- `regenerate(generation)` 仅在历史 Provider 仍启用时复用历史 Provider 和历史模型。
- 历史 Provider 不可用时回退当前启用 Provider，并保留当前模型，避免把不兼容的历史模型带到新 Provider。
- 新增 `regenerateFromHistoryFallsBackWhenStoredProviderIsDisabled` 回归测试。

1. **Less is More** — 减少视觉噪音，留白即信息
